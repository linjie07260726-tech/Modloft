# Modloft · 铝型材家具设计器

面向小面积 / 出租房的可拆装铝型材家具设计工具：输入你的身材和房间条件，自动算出结构尺寸、BOM 切割单和拼装步骤。搬家可拆走，按单量裁即可组装。

**纯前端 · 单文件 · 零依赖** —— 双击 HTML 就能用。

## 解决什么问题

用铝型材（工业框架材料）DIY 家具是小空间租房的热门方案：结实、可拆装、搬家能带走。但门槛在于——尺寸怎么定、料买多少、怎么拼。

这个工具把 **人体工学 → 结构尺寸 → 采购清单 → 拼装指引** 整条链路自动化。

## 文件

| 文件 | 是什么 |
| --- | --- |
| `index.html` | 参数化引擎原型（高架床）：输入身高 / 房间净高 / 床宽 / 床下用途 → 层高校验、侧视比例图、BOM 切割单（含估价）、拼装步骤 |
| `flow.html` | 单品定制流程模拟器：分步表单，选什么家具后面就问什么（规则卡驱动），终点输出交给引擎的 JSON |

## 技术要点

- **单文件零依赖**，无构建、无服务器，浏览器直开
- **数据 / 计算 / 渲染三层分离**：引擎是纯函数，不碰 DOM —— 为将来接 Three.js 3D 预览预留的架构口
- **规则卡架构**：表单项、推算逻辑全部数据驱动，新增家具品类只加一张卡，渲染代码零改动
- **防翻车校验**：层高不够、结构比房间还高，直接报错而不是算出一份装不下的清单
- 中文注释即文档，代码按教材标准写

## 路线
